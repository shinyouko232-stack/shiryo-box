  資料箱(しりょうばこ)  ―  絵の資料を集めて眺めるアプリ
  2026年10月24日版
==============================================================

アイデア出しマン　マレン
作成　claude

■ これは何?
--------------------------------------------------------------
ネットや手元で見つけた画像を、自分のパソコンの中に集めて整理するアプリです。

  ・画像をドラッグ&ドロップ / コピペで取り込める
  ・名前や「色」で資料を探せる(「緑っぽい色が30%以上」のような大まかな検索と、
    HEX / RGB / CMYK / HSB のカラーコードでの検索)
  ・ボードに資料を並べて、拡大縮小・左右反転・白黒で確認できる
  ・ボードを小さい別ウィンドウにして、お絵描きソフトの横に常に表示できる
  ・CMYK の画像、TIFF、PSD(Photoshop)も表示できる


■ 動作環境
--------------------------------------------------------------
  ・Windows 10 / 11(64ビット)
  ・Microsoft Edge WebView2 ランタイム
      Windows 11 には最初から入っています。Windows 10 も、ほとんどの場合は
      入っています。起動しない場合は、Microsoft の公式サイトで
      「WebView2 ランタイム」を検索してインストールしてください。
  ・インターネット接続は、URL から画像を取り込むときだけ必要です。
  ・Mac では動きません。


■ はじめかた
--------------------------------------------------------------
1. 好きな場所に新しいフォルダを作ります(例:ドキュメント\資料箱)。
2. その中に「資料箱.exe」を入れます。
3. 資料箱.exe をダブルクリックすると起動します。

  ※ 資料は exe と同じフォルダの中の「library」フォルダに保存されます。
     デスクトップに exe を直接置くと、デスクトップに library ができるので、
     必ず専用のフォルダを作ってから入れてください。
     「C:\Program Files」の中は書き込みが制限されるので置かないでください。

  ※ 初めて起動すると「Windows によって PC が保護されました」と青い画面が
     出ることがあります。これは個人が作ったアプリで、配布元を証明する署名が
     付いていないためです。配布者から直接受け取ったものであれば、
     「詳細情報」→「実行」で起動できます。
     出どころの分からない資料箱.exe は実行しないでください。
     ウイルス対策ソフトが誤って警告することもあります。


■ 使い方
--------------------------------------------------------------
【画像を取り込む】
  ・画像ファイルを窓にドラッグ&ドロップ、または「+ 画像を追加」
  ・ブラウザの画像をそのまま窓にドラッグ
  ・ブラウザで画像を右クリック →「画像をコピー」→ 資料箱で Ctrl+V
      (いちばん確実な方法です。どのサイトでも使えます)
  ・URL をコピーして資料箱で Ctrl+V
      - pixiv の作品ページ → 全ページを原寸で取り込み(1回20枚まで)
      - X(Twitter)のポスト → 添付画像を原寸で取り込み(動画はサムネイル)
      - その他のページ → そのページの代表画像を取り込み
  ・pixiv / X の画像をドラッグした場合も、自動で原寸を取りに行きます。
  ・使える形式:PNG / JPEG / GIF / WebP / BMP / AVIF / TIFF / PSD

  うまく取り込めないとき:
    ログインしないと見られない作品(pixiv の R-18 など)、鍵アカウント、
    削除されたポストは URL からは取れません。画像を右クリック →
    「画像をコピー」→ Ctrl+V で取り込んでください。

【探す】
  ・左上の欄で名前検索
  ・「色で探す」は2種類あります。
    「大まか」 … 赤・橙・黄・緑・水色・青・紫・ピンク・茶・肌・白・灰・黒 から
                  1つ選ぶと、その系統の色が「◯%以上」ある絵が、多い順に並びます。
                  スライダーで「◯%以上」を変えられます。
    「カラーコード」… 色を選ぶか数値を入れると、その色に近い色を含む絵が
                  近い順に並びます。
  ・絞り込み中は、各資料にその色の割合が表示されます
  ・右上の「色の表記」で HEX / RGB / CMYK / HSB を切り替えると、
    カラーコードの入力欄と、プレビューに出る色の数値がその形式になります
  ・資料の下の小さい丸(色)をクリックすると、その色でカラーコード検索します
  ・初めて起動したときや、古い版で取り込んだ資料は、色の解析に少し時間が
    かかります(解析中の枚数が表示されます)

【見る・整理する】
  ・クリックで選択、ダブルクリックで大きく表示(色の割合も見られます)
  ・大きく表示した画面の「白黒で見る」で、白黒にした画像と
    白〜黒の割合(明・中・暗の3段階と、10段階の内訳)を見られます
  ・大きく表示した画面で名前を変えられます
  ・削除すると library\trash フォルダに移動します(完全には消えません)

【ボード】
  ・ライブラリの資料をつかんで(左クリックを押したまま)ボードの上で離すと、
    その場所に置けます。複数選択してからドラッグすると、まとめて置けます。
  ・上の「並べる」でライブラリとボードを左右に並べて表示できます。
    ボードを「別ウィンドウで開く」にした場合も、メインの窓のライブラリから
    別ウィンドウのボードへドラッグできます。
  ・資料の右上の「+」、または選択して「ボードに追加」でも置けます
  ・ドラッグで移動、右下の■で大きさを変更、ホイールでズーム
  ・背景をドラッグでスクロール、Delete キーでボードから外す
  ・「白黒」で明暗の確認、「⇋ 反転」で左右反転
  ・ボードの画像もダブルクリックで大きく表示できます。
    ボードを「白黒」にしているときは、白黒の割合が表示されます
  ・「✏️ ペン」で、絵の構造のメモを描き込めます(6色・太さ2段階)。
    「消しゴム」で消えるのはペンの線だけで、絵は消えません。
    描き間違いは Ctrl+Z で1つずつ戻せます。Esc で「✋ 移動」に戻ります。
    線はボードに描かれるので、あとから画像だけを動かすと線は元の位置に残ります。
    「クリア」はボードの画像とペンの線をまとめて片付けます
  ・ボードは名前を付けて何枚でも作れます
  ・「別ウィンドウで開く」で小さい窓になり、他のアプリより手前に
    表示され続けます。「📌 最前面」ボタンでオン/オフできます。

【その他】
  ・「📁 フォルダ」で資料の保存フォルダを開けます
  ・資料箱を2回起動しても、2つ目は1つ目と同じデータで開きます


■ データの保存場所・バックアップ・削除
--------------------------------------------------------------
  資料箱.exe と同じフォルダに「library」ができ、その中に保存されます。
    library\images   … 取り込んだ画像(元のファイルそのまま)
    library\trash    … 削除した画像
    library\cache    … TIFF / PSD / CMYK 画像の表示用(消しても自動で作り直されます)
    library\db.json  … 名前・色・ボードの情報

  ・バックアップ:library フォルダごとコピーしてください。
  ・別の PC へ移す:資料箱.exe と library フォルダを一緒に移してください。
  ・images フォルダに画像を直接入れても、「↻ 再読み込み」で取り込まれます。
  ・色の表記などの表示設定は、次の場所に保存されます。
      %LOCALAPPDATA%\ShiryoBox
  ・アンインストール:資料箱.exe と library フォルダ、上の ShiryoBox フォルダを
    削除するだけです(レジストリは使っていません)。
    library を消すと資料も全部消えるので注意してください。


■ 通信とプライバシー
--------------------------------------------------------------
  ・アプリの画面は、自分の PC の中だけで動いています(127.0.0.1)。
    ほかの PC やネットから中身を見られることはありません。
  ・ネットに接続するのは、URL から画像を取り込むときだけです。
    接続先は、取り込もうとしたサイトです。pixiv は www.pixiv.net と
    i.pximg.net、X は cdn.syndication.twimg.com と pbs.twimg.com です。
  ・送るのは取り込みたい URL だけです。ログイン情報や個人情報は送りません。
    アクセス解析や利用状況の送信も一切していません。


■ 困ったとき
--------------------------------------------------------------
  ・「古いバージョンの資料箱が同じ資料フォルダで起動中です」と出る
      → 旧版の黒い画面を閉じてから起動し直してください。
  ・起動しない / 動きがおかしい
      → library\shiryo_box.log にエラーの記録が残っていることがあります。
        配布者に聞くときに一緒に送ってください。
